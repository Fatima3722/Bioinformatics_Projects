# Bioinformatics projects

**[About my research interests and selected computational work](PORTFOLIO.md)**

Educational computational analyses with explicit inputs, reproducible commands and documented limitations.

| Project | Scope |
| --- | --- |
| [Acetylcholinesterase QSAR](computational_Drug_Discovery/README.md) | A pinned public archive, identity-checked descriptors and leakage-aware regression evaluation |
| [OD600 visualisation](Bacterial-Growth-Visualization/README.md) | Validated supplied CSV observations and a clearly labelled synthetic example |

The QSAR workflow uses an archived dataset with incomplete original assay metadata and four supplied descriptors by default. Its README explains those limitations and the optional PaDEL workflow. The growth example is synthetic because the original CSV was not present; it is not presented as measured experimental data.

Each project has its own requirements and run/test instructions. The notebooks and examples are demonstrations, not validated therapeutic predictions or published experimental findings.
